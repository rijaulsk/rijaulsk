# **App Name**: Rijaul Sk Portfolio

## Core Features:

- Sticky Header: Navigation header remains visible on scroll.
- Smooth Scroll Navigation: Enables smooth transitions between sections upon navigation clicks.
- WhatsApp Integration: Direct link to WhatsApp for quick inquiries and contact.
- Portfolio Showcase: Dedicated section to display recent projects with images and descriptions.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for headlines and key CTAs, conveys trust and expertise.
- Accent color: Cyan (#06B6D4) for interactive elements, highlighting a modern and engaging feel.
- Background color: Light gray (#F9FAFB), offering a clean and spacious canvas for content display.
- Body font: System fonts (sans-serif) ensure fast loading times and broad compatibility.
- Headline font: System fonts (sans-serif) maintains a modern and accessible feel.
- Single-page layout with clearly defined sections.
- Subtle animations: smooth scroll, hover effects.
